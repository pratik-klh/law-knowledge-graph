# Walker v. Armco Steel Corp. (1980)

## Rule
[[Hanna v. Plumer|Hanna]] applies **only** if there is a **direct collision** between the state law and the federal rule.
- Is there a legitimate federal rule **directly on point**? (The rule is read **narrowly**.)
  - **Yes:** the FRCP wins.
  - **No:** do the [[Byrd Balancing Test|Byrd analysis]].

(Context: FRCP 3 (commencement) did not displace a state rule tolling the statute of limitations only upon service.)
