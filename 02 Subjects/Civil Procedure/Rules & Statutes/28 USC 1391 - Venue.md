# 28 U.S.C. §1391: Venue

| Subsection | Rule |
|---|---|
| (b)(1) | If all Ds reside in the same state: any district where any D resides |
| (b)(2) | District where a substantial part of the events occurred, or where the property at issue is situated |
| (b)(3) | Otherwise: any district where any D is subject to PJ for the action |
| (c)(1) | Individuals reside where **domiciled** |
| (c)(2) | Corporations reside anywhere they're subject to **PJ** |
| (c)(3) | With both domestic and alien Ds, the suit may be brought in any district where a D resides |
