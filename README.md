# Law Knowledge Graph

An [Obsidian](https://obsidian.md) vault of law school notes. Raw course documents are broken down into small linked Markdown notes, so the topics connect into a navigable knowledge graph.

## Subjects
- **Civil Procedure**: personal jurisdiction, subject matter jurisdiction, venue, Erie, pleadings, joinder, discovery, and summary judgment. Start at [`02 Subjects/Civil Procedure/Civil Procedure.md`](02%20Subjects/Civil%20Procedure/Civil%20Procedure.md).

## Structure
```
00 Inbox/            quick captures, sorted into a subject later
01 Raw Sources/      original .docx outlines and notes (not edited)
02 Subjects/<Subject>/
  <Subject>.md       Map of Content: the starting point for the subject
  Topics/            hub note for each major unit
  Concepts/          one doctrine per note
  Cases/             facts, issue, holding, significance
  Rules & Statutes/  FRCP rules, U.S.C. sections, constitutional text
  Frameworks/        exam checklists and flowcharts (Mermaid)
03 Templates/        note templates
99 Attachments/      images and diagrams
```

## Usage
1. Clone the repo and open the folder as a vault in Obsidian.
2. Open **Graph view** (`Cmd/Ctrl + G`). It's preset to show only `02 Subjects`, with nodes colored by note type: cases, concepts, rules, topics, and frameworks.
3. Notes use frontmatter (`type`, `topic`, `aliases`, `tags`). Abbreviations such as `[[PJ]]` or `[[Rule 12(b)(6)]]` resolve through aliases.

See [`Home.md`](Home.md) for the full conventions.

> These are personal study notes, not legal advice.
